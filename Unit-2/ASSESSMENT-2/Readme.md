# CSA17 – Artificial Intelligence Scenario Based Assignment

## Course Details
- **Course Name:** Artificial Intelligence
- **Course Code:** CSA17
- **Assessment:** Assessment Tool 2 – Scenario Based Assignment

## Description
This repository contains the solutions for the CSA17 Artificial Intelligence Scenario Based Assignment. The assignment focuses on applying AI algorithms to solve real-world problems using search techniques, optimization methods, constraint satisfaction, and game-playing strategies.

## Topics Covered
1. Greedy Best-First Search
2. A* Search Algorithm
3. Hill Climbing
4. Simulated Annealing
5. Genetic Algorithm
6. Online Search Agent
7. Constraint Satisfaction Problem (CSP)
8. Backtracking Search
9. Constraint Propagation
10. Minimax Algorithm
11. Alpha-Beta Pruning

## Scenarios Included
- AI-powered Drone Route Planning
- Smart City Traffic Signal Optimization
- Mars Rover Navigation
- University Exam Timetable Scheduling
- Real-Time Strategy Game AI

## Technologies Used
- Artificial Intelligence Concepts
- Search Algorithms
- Optimization Techniques
- Constraint Satisfaction
- Game Tree Search

## Learning Outcomes
- Understand informed and uninformed search techniques.
- Apply optimization algorithms to real-world scenarios.
- Solve constraint satisfaction problems efficiently.
- Analyze decision-making in dynamic environments.
- Implement game-playing AI using Minimax and Alpha-Beta Pruning.
